# SaaS Market Research Plugin

A Python plugin that equips AI agents with deterministic data-gathering capabilities to validate software demand.

### Features:
- Direct API connections to GitHub, ProductHunt, and StackOverflow.
- Secure `.env` credential management.
- **Web-Scraping Fallback**: Automatically switches to scraping if API keys are not provided by the user.
